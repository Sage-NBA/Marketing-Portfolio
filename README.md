## 📌 Overview

This project is a full-featured marketing agency web presence engineered to drive client acquisitions. Built with React, TypeScript, and Tailwind CSS, it couples performance-focused architecture with interactive lead-generation tools, including an in-browser Search Engine Results Page (SERP) simulator and automated site audit form.

---

## ✨ Features

- 🎯 **Hero & Value Proposition**: Engaging headline typography, clear CTAs, and performance trust metrics.
- 🔍 **Interactive SERP Simulator**: Live preview tool letting clients test meta titles, URLs, and descriptions to visualize how their brand renders in Google Search.
- 📊 **Website Audit Form**: Interactive form enabling prospects to request automated SEO and marketing audits directly.
- 💼 **Strategy & Service Offerings**: Structured breakdown of growth marketing services, deliverables, and growth frameworks.
- ❓ **FAQ Section**: Accordion-style frequently asked questions addressing common client inquiries.
- 📱 **Mobile-First & High Performance**: Ultra-fast load times with responsive layouts across mobile, tablet, and widescreen viewports.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sage-NBA/Marketing-Portfolio.git
   cd Marketing-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
